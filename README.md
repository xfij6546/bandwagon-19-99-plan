## 这个套餐已经绝版，现在只有老用户能续费

这批套餐最后一次上架是 2018 年 1 月的补货，当时一次放出三款年付 19.99 美元的特价方案：两款 KVM 架构、一款 OpenVZ 架构，补货时间甚至精确到了凌晨四点。之后再没回到过货架。

架构决定了这三款的命运分岔：

- **OpenVZ 版（10G VZ – PROMO）**：已经不能续费。搬瓦工后来全面淘汰了 OpenVZ 架构，所有 OVZ 方案都停止续订，数据只能迁走。
- **KVM 版**：只要套餐还是 KVM 架构，就可以一直续费，目前没有任何要淘汰的迹象。

所以同一个问题，两类人拿到的是完全不同的答案。新用户：官方现售方案最低也要 49.99 美元/年，限量版更是 79.99 美元起步，别把精力花在等一个不会回来的价格上。老用户：续费入口一直在，价格维持原样，这个后面细说。

## 两款 19.99 套餐怎么区分：常规版和 QNET 版配置差在哪

KVM 架构的 19.99 套餐其实有两个版本，差异不小，续费前先确认自己手里是哪一款：

| 项目 | 10G KVM – PROMO（常规版） | SPECIAL 10G KVM PROMO V3（QNET 版） |
| --- | --- | --- |
| CPU / 内存 | 1 核 / 512 MB | 1 核 / 512 MB |
| 硬盘 | 10 GB SSD | 10 GB SSD |
| 月流量 | 500 GB | 1000 GB |
| 带宽 | 1 Gbps | 1 Gbps |
| 可用机房 | 8 个（DC3 CN2、DC8 ZNET、DC4 MCOM、Fremont 等） | 仅 DC2 QNET |
| 机房迁移 | 支持（切到 CN2 机房后流量按 1/3 计） | 不支持 |
| 价格 | 19.99 美元/年 | 19.99 美元/年 |

分辨方法很简单，看后台的套餐全名：QNET 版全称是 SPECIAL 10G KVM PROMO V3 – LOS ANGELES – CHINA DIRECT ROUTE，名字里带 CHINA DIRECT ROUTE；常规版就叫 10G KVM – PROMO。

当年 QNET 系列还有一款 39.99 美元/年的 20G 版（1 核、1 GB 内存、20 GB 硬盘、2 TB 月流量，同样锁定 QNET 机房、不可迁移），一并提一下方便对照。

两款的核心区别就两点：常规版流量只有一半，但能换机房；QNET 版流量翻倍，却被锁死在 QNET 机房。当年不少人冲着“洛杉矶直连”买的 QNET 版，这个选择的后续变化，在下面香港 HK85 那一节会讲到。

## 要不要续费：价格不用犹豫，内存才是门槛

价格上没什么可纠结的。19.99 美元一年，折合人民币一百多块，这个价位在现售套餐里已经不存在——最便宜的 KVM 20G 也要 49.99 美元/年，是它的 2.5 倍。算一笔三年的账更直观：老套餐折后三年大约 56 美元，还不够现售最便宜套餐付一年多的。

真正需要掂量的是 512 MB 内存的实际边界：

- **适合**：当 Linux 学习机，想到什么技术就上去重装系统折腾 shell；跑占用很低的轻量服务；写个访问量不大的个人博客，嫌慢可以再套一层 CDN。
- **勉强**：老版本 PHP 和 MySQL 环境下建小站，当年 128 MB 内存的 VPS 都能做网站，512 MB 真要做也行，前提是访问量不高。
- **不适合**：新版 PHP 7 或较新的 MySQL 至少要 1 GB 内存，现代建站环境基本跑不起来；对线路有要求的人也一样，这套餐用不了 DC6/DC9 CN2 GIA、日本软银和香港 CN2 GIA 机房。

用得上就续，一年一百多块买个长期在线的实验机不亏；确定用不上，也不必为“绝版”两个字硬续。续费价格不用担心，这几年的账单一直是 19.99 美元，用优惠码后 18.79 美元，没有变过。

这是很多 QNET 用户自己都没注意到的事。大约从 2022 年起，一部分 QNET 套餐被搬瓦工悄悄迁移到了新上线的香港 HK85 机房，配置和流量都没变——相当于 19.99 美元一年、1 TB 月流量、香港机房，当年花 QNET 的钱，现在白得了香港的待遇。

判断自己有没有被迁移，看 IP 就行：QNET 套餐的 IP 如果是 45.78.xx.xx 段，这台 VPS 已经在香港 HK85；其他 IP 段则大概率还留在 QNET。迁移过程中 IP 地址本身不变。另外，机房虽然换了，“不可迁移机房”的限制还在，后台仍会提示 Plan does not support migrations。

不想续但想留在搬瓦工的用户还有一条路：这款套餐支持升级，常规 KVM、CN2、CN2 GIA 都在可升级范围内，后台就能操作。

没用上这套餐又想用 HK85 机房的新用户，只能买香港 HK85 限量版：1 核、1 GB 内存、20 GB SSD、500 GB 月流量，年付 79.99 美元，上线后一度长期缺货，想买得蹲补货通知：👉 查看香港 HK85 限量版是否补货

## 关于 19.99 套餐的几个常见问题

**19.99 套餐以后还会补货吗？**
不会。2018 年 1 月之后这款套餐再没有上架过，官方现售方案最低 49.99 美元/年，等一个不会回来的价格没有意义。

**OpenVZ 版的 19.99 套餐还能续费吗？**
不能。所有 OpenVZ 架构方案都已停止续费，这是架构层面的整体淘汰；KVM 版不受影响。

**续费价格会变吗？**
至今没变。近几年的续费都是 19.99 美元/年，用优惠码后 18.79 美元。

**能不能从 19.99 套餐升级？**
可以。常规版和 QNET 版都支持升级，QNET 版可升往常规 KVM、CN2、CN2 GIA 等套餐，在后台自助操作。

**QNET 版怎么确认自己是不是已经在香港？**
看 IP：45.78 开头的 IP 段已随迁移进入香港 HK85，且 IP 地址保持不变；其他 IP 段仍在 QNET。
